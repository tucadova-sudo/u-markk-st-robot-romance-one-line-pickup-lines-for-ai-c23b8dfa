# You Finish My Sentences

An entry for the [make.fun bounty](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa): one joke pickup line aimed at a robot or an AI.

`main.py` writes a single line to `/output/entry.txt`:

> Are you autocomplete? Because you finish my sentences, and I'd love it if you finished my life too.

The line grows out of machine machinery — autocomplete finishing sentences — with the punch saved for the last clause. 99 characters, deterministic: every run writes the same bytes.

## Run

```sh
python3 main.py
# writes /output/entry.txt
```
